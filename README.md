# Global Force — Rough Website Concept

A lightweight, single-page static website draft for a new federal professional-services contractor.

## Purpose
This is intentionally a structure-first concept, not a branding exercise. It uses a simple navy/white system and a text-only placeholder mark so the content hierarchy can be evaluated without getting locked into a visual identity.

## Page structure
1. Hero / positioning
2. Core capabilities
3. Delivery approach
4. Leadership & key-personnel experience
5. Federal contracting information
6. About
7. Contact

## Important placeholders to replace
- Founder / principal name and bio
- Representative individual experience
- UEI
- CAGE code
- Business / socioeconomic status
- NAICS and PSC codes
- Capability statement PDF
- Email, phone, and location

## Why “Experience” instead of “Past Performance” for now
Since Global Force is a new company, the draft avoids implying that prior work performed by the founder or future employees was performed under Global Force contracts. Once the company has its own awards, a Past Performance / Projects section can be added.

## Open locally
Open `index.html` in any browser. No build step or external dependencies are required.
